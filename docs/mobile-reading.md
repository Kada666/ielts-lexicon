# 手机阅读与闪卡交互

## 词库

- 手机宽度≤760px改为左右两列：左侧英文单词，右侧中文义。
- ○ / △保留为轻量符号，来源压为L01等小字；不显示学习状态、下次复习时间，也不套用隐藏的学习状态筛选。
- 正常词形22px、长词19px、中文17px；搜索与编辑输入至少16px，降低iOS自动放大输入框的干扰。
- 搜索、List和初始分类筛选保留。滚动到末尾自动续载，手动继续按钮作为备用；132词可连续纵向复盘。

## 闪卡

- 主要呈现单词、音标/发音入口、中文义、首选联想；例句、搭配、词性和其他候选仍保存在完整词条编辑器中。
- 单词约44px，中文义24px，联想18px。展开、收起、前后切换、评分等触控目标至少44px。
- 顶部收起按钮在滚动时可见；手机底部评分与切换区便于操作。
- 上一个/下一个只切换卡片，不记作复习；只有明确选择评分才写历史。本轮已评分卡可回看，评分按钮禁用，避免重复写入。
- 550ms长按联想区打开快捷编辑。手指移动超过12px或触控取消会取消长按，允许正常滚动；也有“编辑”按钮。
- 快捷编辑只更新当前首选记忆法，保留其他候选、释义、例句和学习记录。词根/词源/词族修改继续标为待审核，不冒充已核验。

## 单词发音

点击音标或喇叭，使用浏览器Web Speech API朗读英文词形，默认请求 `en-GB`，速度0.85。优先选择本机English (UK)语音；不把其他口音冒称为英式。切换词或页面会取消上一段朗读。没有音标的词仍可点击“听英式发音”。

这是设备语音合成，不是雅思官方录音，也不是内置MP3。可用语音由浏览器/系统决定；部分语音服务可能需要网络。离线朗读需要本地English (UK)语音，缺少时提示在系统安装；词库、翻卡、评分不依赖发音服务，仍可离线工作。

雅思并不要求唯一英式口音，默认英式仅为统一练习偏好：[IELTS官方说明](https://ielts.org/news-and-insights/ielts-speaking-tips-common-myths-and-how-to-overcome-them)。设备语音列表和本地/远程区别见 [MDN getVoices](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices)、[MDN localService](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisVoice/localService)。

## 验证边界

自动验证320、390、430px无横向溢出；132词连续加载；真实Chrome触控事件的长按、滚动取消；快捷编辑刷新保留；前后切换不评分、已评分卡防重复写入；大字体和按钮高度。

发音自动测试使用隔离的设备语音模拟，确认发音按钮传入正确单词、en-GB和本地英式语音；另测试离线不选远程语音。自动测试不等于真实手机扬声器听感验证；iOS语音安装和实际音量须以设备为准。
